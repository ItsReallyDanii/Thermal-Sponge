### Threshold fix (checkpoint change)

`src/benchmark_baselines.py` previously used a hardcoded `0.5` threshold for
void/solid classification, inconsistent with `VOID_THRESHOLD = 0.60` in `constants.py`.
This was fixed in this checkpoint to import and use `VOID_THRESHOLD`.

**Impact:** If `benchmark_baselines.py` is re-run, `results/baselines/baseline_metrics.csv`
will change (slightly different solid fractions). The committed CSV was produced with the
old 0.5 threshold. C2 claim status is NOT expected to change materially, but the
raw density values will shift. The fix is correct; the old committed CSV is labeled stale.
